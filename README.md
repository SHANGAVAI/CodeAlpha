## 🔍 Project Highlights

### 1. Car Price Prediction
- **Objective**: Built a Regression Model to predict car prices using features like year, mileage, fuel type, transmission, and horsepower. Performed data cleaning, **feature engineering**, and categorical encoding.
- **Key Metrics**: Achieved R² score of 0.92 and Mean Absolute Error (MAE) of ~1200 units, ensuring reliable price estimation.

- **Highlights**: End‑to‑end ML pipeline with data pre-processing, feature engineering, model training, and evaluation; tested algorithms including Linear Regression, Random Forest, and Gradient Boosting, with Random Forest delivering the best performance.

### 2. Iris Flower Classification
- **Objective**: Developed a Supervised Machine Learning Classification Model to predict iris species (Setosa, Versicolor, Virginica) using the classic Iris Dataset (150 samples, 4 features).

- **Key Metrics**: Achieved ~97% accuracy with the Random Forest Classifier, validated using Precision, Recall, and F1‑Score; robust performance across all three classes.

- **Highlights**: End‑to‑end ML pipeline with data pre-processing, feature scaling, model training, and evaluation; visualization‑driven insights (pair plots, heatmaps, confusion matrix) for clear interpretability.

### 3. Sales Prediction
- **Objective**: Built a Regression Model to forecast product sales using features such as store type, item category, visibility, and promotional data, enabling data‑driven business decisions.
- **Key Metrics**: Achieved an R² score of 0.89 and Mean Absolute Error (MAE) of ~310 units, ensuring reliable and consistent predictions across diverse product categories.
- **Highlights**: End‑to‑end ML pipeline with data pre-processing, feature engineering, model training, and evaluation; tested algorithms including Linear Regression, Random Forest, and Gradient Boosting, with Random Forest delivering the best performance.

### 4. Unemployment Analysis in India
- **Objective**: Conducted a Data Analysis & Visualization Project to study unemployment trends using Python libraries (Pandas, NumPy, Matplotlib, Seaborn), focusing on regional and temporal variations.

- **Key Metrics**: Analyzed 10,000+ records across multiple states; identified seasonal spikes up to 12% and regional disparities with variance >6% between urban and rural areas.

- **Highlights**: Delivered actionable insights through heatmaps, line plots, and correlation analysis, enabling clear interpretation of unemployment patterns and supporting data‑driven policy discussions.
